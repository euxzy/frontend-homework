# SPMI Frontend Homework

Starter repository untuk frontend application Sistem Penjaminan Mutu Internal (SPMI).

## Technology

- Nx monorepo
- Nuxt 4
- Vue 3 dan TypeScript
- `@nuxtjs/i18n`
- Tailwind CSS 4
- Sicoco Next (`@sutekitechid/sicoco-v3-next`)
- Vitest dan Playwright

## Prerequisites

- Node.js 22

## Setup

```sh
npm install
```

## Commands

```sh
npm run dev
npm run build
npm run lint
npm run test
npm run typecheck
```

Aplikasi tersedia pada `http://localhost:4200` saat development server berjalan.

## Application

Source code aplikasi berada di `apps/spmi`. Halaman login disediakan sebagai baseline aplikasi; fitur homework dan desain terkait akan dibagikan bersama assignment.
